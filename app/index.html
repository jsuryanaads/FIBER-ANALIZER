Bangun jalur fiber berdasarkan kabel dan core nyata.

Satu kabel dapat memiliki 6C, 12C, 24C, 48C dan seterusnya. Core dipilih saat continuity, bukan membuat kabel baru.

OLTPortOTB24CJB16CJB26CJB3...CUSTOMER

Aturan inti

  • 1 kabel = 1 segmen fisik.
  • Core 1..N dibuat otomatis dari fiber_count.
  • Continuity menentukan core masuk → core keluar.
  • Core rusak dapat diganti dengan core spare.
  • Trace mengikuti mapping aktual.
